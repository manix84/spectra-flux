# Contributing 💿

Thanks for helping improve SpectraFlux. 🎶

Please read the [Code of Conduct](CODE_OF_CONDUCT.md) before participating. For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Local Setup 🛠️

1. Install Node.js 20.19 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Quality Bar ✨

- 🎛️ Keep visual motion smooth and music-driven.
- 🎯 Prefer small, focused changes.
- ✅ Run `npm run lint` and `npm run build` before opening a pull request.
- 🧪 Run `npm test` when changing core audio, rendering, build, or PWA behaviour.
- 🧾 Use conventional commits where possible, for example `feat: add tunnel preset` or `fix: clamp waveform amplitude`.
- 🔒 Avoid committing local audio files, recordings, browser captures, or personal test data.

## Pull Requests 🚀

Please include:

- 📝 What changed
- 🧪 How it was tested
- 📸 Screenshots or recordings for visual changes when useful
- 🔗 Related issues or follow-up notes, if any

## Issue Reports 🐛

Use the GitHub issue templates when possible. Reproducible bug reports should include the browser, operating system, audio input type, visual mode, and a short recording or screenshot when rendering behaviour matters.
