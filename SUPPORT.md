# Support 🎧

For help and project questions: 🛟

- 🐛 Open a GitHub issue for reproducible bugs.
- 💡 Start a discussion for ideas, presets, and visual design feedback.
- 📹 Include your browser, OS, input type, and a short screen recording for rendering issues when possible.

## Good Bug Reports 🐛

Please include:

- 🌐 Browser and operating system
- 🎧 Input type: file, microphone, tab audio, or system audio
- 🌀 Visual mode and colour theme
- 🔁 Steps to reproduce
- 📸 Screenshot or short recording when the issue is visual

## Security Reports 🔐

Do not open a public issue for security-sensitive reports. Follow [SECURITY.md](SECURITY.md).

## Community Guidelines 🌈

Project participation follows the [Code of Conduct](CODE_OF_CONDUCT.md).
