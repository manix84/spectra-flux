# What's New 🎉

Recent SpectraFlux updates, with the newest items first.

## 1.0.3 🚀

- 🎨 Enhanced visualizer effects with improved bar visibility and colour dynamics.
- ⏯️ Added playback controls with time display and seeking.
- 🖱️ Added audio file drag-and-drop with visual feedback.
- 🔢 Added smart version bump scripts and a pre-commit version workflow.
- 🏷️ Renamed the project from Canvas Wave Spectrum to SpectraFlux.
- ☕ Added screen wake lock support for longer listening sessions.
- 🎛️ Improved the control surface and floating drawer toggle.
- 🧪 Added Playwright end-to-end coverage and production bundle checks.

## Earlier Highlights 🌈

- 🌀 Real-time spectrum, waveform, radial, particle, and abstract visual modes.
- 🎧 File, microphone, and browser-supported tab/system audio capture.
- 📦 PWA manifest, service worker, install icons, and offline shell caching.
